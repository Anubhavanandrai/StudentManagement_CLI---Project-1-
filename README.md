# StudentManagement_CLI---Project-1-

This project is a Core Java based application where concepts of Classes & Objects,Constructor,Polymorphism,Collections,Encapsulation,
Abstraction,Interface,Inheritance,File Handling, Loops and Try-Catch is used.Here user will provide input on CLI and the data will be 
stored in file on the basis of different operations made.
